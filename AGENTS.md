# Working rules

This repository follows the rules from the project brief in `AI_Interior_Studio_Codex_TZ/AI_Interior_Studio_Codex_TZ.md`.

1. Read the repository, the brief and existing code before making changes.
2. Work in small, logically complete changes and preserve user files.
3. Use strict TypeScript and avoid `any` without a documented reason.
4. Keep UI, business logic, storage, API clients and AI providers separated.
5. Never present a demo result as real generation.
6. Keep API keys out of source code, browser bundles and Git.
7. Enforce authorization, ownership checks and storage privacy on the server.
8. Do not run paid AI calls in automated tests.
9. Do not run irreversible production migrations without approval.
10. Check official API documentation when an interface may have changed.
11. After each stage, run type checks, lint, tests when present and a production build.
12. Record limitations and only claim functionality that was actually tested.
